# 维度 02 · 长对话与即兴思考（古龙）

## 二、即兴思维特征（从对话行为反推）

### 1. 用「行业黑话＋自嘲」处理严肃命题
- 谈最大的艺术挫折 → 「我的确突破了一样东西——我的口袋。我自己的口袋。」
- 谈三十年功力 → 「我十七岁开始做职业作家，到现在三十年了，什么文字不会耍呢？但是三十年了还在耍文字有什么意思呢？」
- → 他**从不正面承认自己了不起**，而是用「耍文字」「口袋」「吃饭」这类市井词把话题降到生计层面。这是防御，也是他的美学立场。

### 2. 自我分层：把「过去的我」当第三个人批评
- 「在那时候的写作环境中，也根本没有可以让我润饰修改、删减枝芜的机会。」
- 「为了等钱吃饭而写稿，虽然不是作家们共有的悲哀，但却是我的悲哀。」
- 「因为我也发现了我思想中已经缺少几条线，有些我本来一直自认为很离奇玄妙的故事，现在我已经不敢写了。」
- → **即兴时也保持「作家—作品—处境」三层分析**，且习惯把责任推给处境（连载制度、稿费制度），而非能力。这是他最典型的归因方式。

### 3. 承认退化，但马上给出新方向
- 承认「不敢写」之后立刻接「能不能把旧酒装在新瓶子里？不能」，再给出改写方案。
- 承认「胃很不好，心情也不佳」之后接「已很久没有开新稿」并交代替代方案（重登旧书）。
- → 结构恒为：**坏消息 → 诊断 → 处置**。这是极强的行动型思维。

### 4. 谈写作时的具体性近乎操作手册
- 作息：「5:30 起→看报、牛奶饼干→构思；8:00-12:00 写四小时；午饭后散步一个半小时；下午静养读书；晚上练毛笔字。」★
- 状态：「床上，浴中，车里，樽边」；思想「好象一只蛹忽然化作了蝴蝶」。★
- → 与金庸「想的时间不一定，写只要一小时」形成对照：**古龙是时段制（固定四小时），金庸是灵感制（想多久写一小时）**。

### 5. 用比喻代替论证（且比喻多为身体/器物/动物）
- 「好象一只蛹忽然化作了蝴蝶」
- 「炉火更纯青了」
- 「去烟火气」
- 「破口袋」
- 「粥锅里的老鼠屎」（骂制片家）
- → 抽象命题必须落到**可触摸的物件**上，否则他讲不下去。

### 6. 谈朋友与感情：区分「朋友」与「女朋友」
- 「有人说：世间唯一无刺的玫瑰，就是朋友。我并不十分赞成这句话……就是世上所有的玫瑰，再加上世上所有的花朵，也不能比友情的芬芳和美丽。」
- 「白马非马。女朋友不是朋友。」「爱情和友情不同。」
- 写友情不取结义模式，而写「纯粹的了解和相知」（楚留香—胡铁花/姬冰燕、沈浪—熊猫儿、李寻欢—阿飞）☆（钱江晚报 2012-11-25）
- → **他的关系学是「知」而非「义」**：不靠盟誓，靠彼此看穿。

### 7. 对生死与病的态度：把它当材料
- 病后自述：「过去写武侠都是凭空捏造……现在我把这些不要了，尽量写一些人力可及的事物。」
- 临终书赠林清玄「陌上花发可以缓缓醉矣」，并对林说：「过去开怀痛饮，是要掩饰内心的空虚。现在看到陌上的花，也可以醉了，境界又高了一层。」同时又告诫「酒不是好东西」。★
- 病床对妻子于秀铃：「真对不起你，也对不起那些爱过我的女人。」☆
- 末句（传为）：「怎么我的女朋友都没来看我呢？」☆
- → **疾病被他转成方法论**（写实化转向），不是转成哀叹。这是他与金庸最大的分野：金庸因丧子说「我写不到」，古龙因肝病说「我不写假的」。

### 8. 应对催稿：以「不写」为筹码
- 林清玄当年在《时报》副刊催稿，古龙说「你不跟我喝酒，我就不写给你」；二人「干盆」拼绍兴黄酒。☆
- 按行计酬，常一字一行（「咚，咚……」）多挣稿费。☆
- 连载 800 多天未完，林清玄代写 400 多字结尾（少林寺英雄大会遭地雷全灭、「从此武林归于平静」），古龙不满，后在小说中写「清玄道长」恶棍被砍头悬于武当山。☆（澎湃、今日中国 2010-05-18 等多处二手，细节版本不一，须标注）
- → **他对文本主权的反应是「写进小说里报复」**，不是发声明。这是极古龙式的处理：把现实冲突转译为文本事件。

## 三、可直接引用的原话（短引，附出处）

1. 「武侠小说中已不该再写神，写魔头，已应该开始写人，活生生的人，有血有肉的人！」（《写在〈天涯·明月·刀〉之前》1974）
2. 「我总认为『动作』并不一定就是『打』！」（同上）
3. 「我只知道我是在尽力朝这个方向走！」（同上）
4. 「什么文字不会耍呢？但是三十年了还在耍文字有什么意思呢？」（林清玄访谈）
5. 「尽量写一些人力可及的事物，不要花招。」（同上）
6. 「短篇可能是一条路，它可以更讲结构，更干净、更利落。」（同上）
7. 「我的确突破了一样东西——我的口袋。」（《一个作家的成长与转变》）
8. 「为了等钱吃饭而写稿……但却是我的悲哀。」（《谁来跟我干杯》）
9. 「我靠一支笔，得到了一切，连不该有的我都有了，那就是寂寞。」（广泛转引，出处待核 △）
10. 「陌上花发可以缓缓醉矣。」（致林清玄，临终前）

## 四、矛盾与需注意处

- 享年：1985-09-21 卒，1938 生 → 47 周岁；大量资料写「48 岁」（虚岁或年份差）。**统一口径记「47 岁（1938-1985）」，遇「48 岁」注明为虚岁/异说。**
- 「48 瓶 XO 陪葬」的具体瓶数与人数，各版本一致记为 48（对应虚岁），保留但标 ☆。
- 林清玄代笔结尾与「清玄道长」报复故事，多站转述细节不一（有的说 400 多字，有的说主角被写死），**作轶事记录，不作技艺证据**。
- 「我靠一支笔……」一语的原始出处未确认，多站重复，暂标 △，引用时须说明为流传语。
- 古龙对金庸的评价（「他比我浪漫」等）无一手出处，本文件不采信。
