# 维度 05 · 决策记录与启发式（古龙，聚焦写作技艺决策）

> 调研时间：2026-10-22｜只收有具体事件支撑的决策

## 一、写作决策事件清单

### D1｜1956：先写纯文学，后转武侠
- 事件：文艺中篇《从北国到南国》刊于吴恺玄主编《晨光》（约 1956，「还未及弱冠」）。★
- 决策：1960 以《苍穹神剑》转武侠。
- **启发式**：**先建立文学自我，再进入类型市场。** 这解释了他后来为何始终以「小说」而非「武侠」自我定位。

### D2｜1964-66：以《浣花洗剑录》完成技法革命
- 决策：借《宫本武藏》的「无招胜有招」与心理决斗，改写武打写法。☆
- 后果：确立「不写招式、写气势与心理」的路线。
- **启发式**：**从非武侠文本取法**（日本剑侠、西方小说、推理、电影），是他的核心创新机制。

### D3｜1966-67：《武林外史》定「浪子」，1967《铁血传奇》集四体
- 决策：把武侠/文艺/侦探/推理/寓言熔于一炉。☆
- **启发式**：**类型混血优于类型纯化。**

### D4｜1969：《萧十一郎》先写剧本再写小说
- 决策：逆向工序。
- 后果：对白与场面调度能力大幅提升；陈墨判其小说本质是「对话的艺术」。
- **启发式**：**换载体写一遍，等于给结构做一次外科手术。**

### D5｜1974-04：《天涯·明月·刀》主动实验（散文诗＋蒙太奇＋纯对话楔子）
- 决策：明知风险仍求新求变。
- 结果：45 天被腰斩；自述「突破了我的口袋」。
- 后果：**后半部文风回撤**，回归安全区；但终生认为这次是对的（1982 年仍说「后来都会喜欢」）。
- **启发式**：**创新要付读者成本；付不起就撤回，但不要否认它是对的。**（这是极罕见的「认输但不认错」姿态）

### D6｜1976：与邵氏合作，进入电影时代
- 事件：《流星·蝴蝶·剑》《天涯·明月·刀》被邵氏搬上银幕，缔造「古龙电影时代」。☆
- 决策：主动向影视靠拢（后期大量转编剧）。
- 后果：加速影像化文体；也加速创作力分散与代笔。
- **启发式**：**向更强的媒介学习，但不要把主业交给它。**

### D7｜1979-1981：接受衰退，转向改写旧作
- 决策：不再强开新稿，转而「旧书新登」与改写。
- 自述：「能不能把旧酒装在新瓶子里？不能。……所以我才想到要把那些故事改写，把一些枝芜、荒乱、不必要的情节和文字删掉，把其中的趣味保留，用我现在稍稍比较精确一点的文字和思想再改写一遍。」★
- **启发式**：**能力下降时，把剩余能力投到「重写」而非「新写」。**（与金庸 D4/D5 惊人一致）

### D8｜病后：从「凭空捏造」转向「写实」
- 决策：「尽量写一些人力可及的事物，不要花招，注意气氛的酝酿营造，讲求结构的一气呵成。」★
- **启发式**：**身体的限制可以转化为美学纲领。**

### D9｜连载制度下的稿费策略
- 决策：按行计酬 → 一字一行（「咚，咚……」）多挣稿费。☆
- 后果：文体被经济结构塑造（短句短段部分源于此）。
- **启发式**：**形式常常是制度的产物，不全是美学选择。**（改稿时须分辨「这是风格还是习惯」）

### D10｜对代笔与伪书的默许
- 决策：高峰期大量署名作品由他人代笔或伪托，未系统清理。
- 后果：文本归属混乱，学术地位受损。☆
- **启发式（反面）**：**放任署名失控，等于放弃作品的长期资产。**

## 二、可提炼的决策启发式（跨事件复现 ≥2 次）

| 启发式 | 复现事件 |
|---|---|
| 1. 从非本类型取法 | D2、D4、D6 |
| 2. 类型混血 | D3、D4 |
| 3. 换载体思考结构 | D4、D6 |
| 4. 创新先算读者成本 | D5、D9 |
| 5. 衰退期转重写 | D7（对应金庸 D4/D5 同构） |
| 6. 限制即纲领 | D8 |
| 7. 形式是制度的产物 | D9 |
| 8. 情感冲突驱动动作 | D5、D8 |
| 9. 短篇优先于长篇结构 | D5 后自述「短篇可能是一条路」 |
| 10. 认输不认错 | D5 |

## 三、反例：做拧的决策（诚实记录）

- **《天涯·明月·刀》后半部回撤**：保住连载却损失了作品完整性，导致该书前后风格断裂（新浪看点 2020-12-10 明确指出「前面大段的内心独白和意境渲染，人物对白冗长。重新连载后，后面的文风大变」）。**这是他自己制造的结构伤。**
- **代笔默许**：短期收益（产量、收入），长期代价（学术地位、文本可信度）。
- **影视优先**：1976 后把大量精力投给电影公司，创作质量下滑，1979 进入衰退期。
- **健康管理为零**：吟松阁事件、酗酒、肝病——把身体当耗材，直接终结了创作生命（47 岁）。

## 四、决策风格画像

1. **赌徒型创新**：明知读者不接受仍要发一次，输了下一次退回。
2. **工序型学习**：写剧本、看电影、读西方小说——凡能提升手艺的都学，不怕丢面子。
3. **对制度高度敏感**：稿费、连载天数、报社压力，全部直接写进他的美学选择。
4. **不做长期资产管理**：对文本归属、版权、健康都不设防——与金庸形成极端反差（金庸创办明河社、系统修订、严控授权）。
5. **诚实的失败者**：他把自己最大的失败（口袋论）写成公开文本，这是极罕见的自我记录。

## 五、对「写作顾问」的直接可用结论

- 判断一段写不动的稿子：**先问「冲突在哪」**——情感冲突还是事件冲突？都没有，就删。
- 处理「读者不买账」：区分**读者没准备好**与**自己没写好**。前者可保留，后者必须改——古龙的错误在于没分清，一律回撤。
- 学古龙要学：句法、气氛、对话、留白。**不要学**：长篇结构、连载凑稿、一字一行的稿费习惯。
- 修订旧作时优先做三件事：删枝芜、留趣味、用「更精确的文字和思想」重写。
